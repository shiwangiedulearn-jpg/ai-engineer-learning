# 🔎 Semantic Search Engine

A simple **semantic search engine** that retrieves relevant documents based on **meaning** rather than exact keyword matching.

##  What I Learned

* Embeddings
* Sentence Embeddings
* Cosine Similarity
* Semantic Search
* Document Retrieval

##  What I Built

A search system that converts documents and queries into **vector embeddings** and uses **cosine similarity** to find the most relevant documents.

##  Architecture

```text
Documents
    ↓
Embedding Model
    ↓
Vector Representations
    ↓
Query Embedding
    ↓
Cosine Similarity
    ↓
Top Relevant Documents
```

##  Key Takeaway

This project helped me understand the fundamentals of **semantic search and the retrieval layer used in modern RAG and AI applications**.
